# 🐷 아기돼지 삼형제 메타버스 동화 게임 — 기능 명세서

문서 버전 v1.0 | 관련 문서: 01_기획서.md, 03_정책서.md

## 1. 시스템 개요

| 항목 | 내용 |
|---|---|
| 렌더링 | 3D 실시간 렌더(Three.js / React Three Fiber 권장) |
| 카메라 | 1인칭, FOV 75~80°, 헤드밥 최소화 |
| 조작 입력 | 자이로/드래그(시점 회전), 탭-투-무브 화살표(이동), 드래그/탭(오브젝트 상호작용), 웹캠 포즈 인식(미니게임 전용) |
| 포즈 인식 | TensorFlow.js MoveNet(SinglePose Lightning) 또는 MediaPipe Pose |
| 저장 | 씬 전환 시 자동 체크포인트 |
| 사운드 | BGM(루프) + SFX + 나레이션(TTS 또는 성우 음원) 3레이어 믹싱 |

## 2. 공통 UI 컴포넌트 기능 명세

### 2-1. 상단 나레이션 자막 박스
| 항목 | 명세 |
|---|---|
| 위치/크기 | 화면 상단 8% 지점, 가로 70% × 세로 12% |
| 표시 로직 | 대사 데이터(화자ID, 텍스트, 오디오URL) 수신 → 화자별 테두리 컬러 매핑 → 타이핑 애니메이션(40ms/글자) 실행 |
| 화자 컬러 매핑 | 나레이션 `#B0B0B0` / 엄마 `#FFD966` / 늑대 `#B39DDB` / 주인공(선택 캐릭터 컬러 따름) |
| 입력 | 자동재생, 우측 상단 "스킵" 버튼으로 즉시 완성 텍스트 표시 후 다음 대사로 이동 |
| 사운드 트리거 | 자막 등장 시 팝업 SFX 1회 재생 |
| 예외 처리 | 오디오 로드 실패 시 텍스트만 표시하고 타이핑 애니메이션은 정상 진행 |

### 2-2. 1인칭 손/배 오버레이
| 항목 | 명세 |
|---|---|
| 표시 영역 | 화면 하단 0~30%, 카메라 고정(패러랭스 없음) |
| 캐릭터별 파라미터 | `characterId`에 따라 손 색상·의상 텍스처를 런타임에 교체(단일 컴포넌트 + 파라미터 주입 방식) |
| 배 노출 조건 | 카메라 pitch ≤ -60° 진입 시 배 메쉬 opacity 0→1 페이드인 |
| 성능 고려 | 손/배는 항상 렌더되는 오브젝트이므로 폴리곤 예산을 낮게 유지(합산 1,000tri 이하 권장) |

### 2-3. 이동 화살표 UI
| 항목 | 명세 |
|---|---|
| 생성 조건 | 씬 진입 시 또는 대사 종료 이벤트 발생 시, 목적지 좌표에 월드 스페이스 마커 생성 |
| 인터랙션 | 탭/클릭 시 `moveTo(target, speed=1.2m/s)` 호출 → 자동 보행 애니메이션 + 카메라 워크사이클 이펙트 |
| 도착 판정 | 캐릭터 좌표와 목적지 좌표 거리 < 0.3m 시 도착 이벤트 발생, 마커 제거 및 다음 트리거 실행 |
| 파티클 | 초당 2개 스파클 파티클 방출(빌보드 처리) |

### 2-4. "참 잘했어요" 도장 UI
| 항목 | 명세 |
|---|---|
| 트리거 | 엔딩 시퀀스 내 지정 타이밍(콘페티 낙하 2초 후)에 자동 호출 |
| 애니메이션 시퀀스 | 낙하(0.4s) → 바운스 스케일(1.3→1.0, 0.3s) → 스탬프 임팩트(플래시+카메라 미세 진동) → 대기(1.5s) → 페이드아웃 |
| 후속 처리 | 페이드아웃 완료 시 씬A(표지)로 상태 초기화 후 복귀, "다른 돼지로 다시하기" 버튼 노출 |

## 3. 씬별 기능 명세

### 3-1. 씬A — 책 표지
| 기능 | 명세 |
|---|---|
| 초기 로딩 | 책 표지 메쉬/텍스처, BGM(오르골 루프) 프리로드 |
| 부양 애니메이션 | y축 sin파 진폭 ±2cm, 주기 3초 무한 루프 |
| 들어가기 버튼 | 시선(레이캐스트) 또는 터치 히트테스트로 조준 판정 → 확정 입력 시 클릭 SFX + `transitionTo('B')` 호출 |
| 트랜지션 | 책 열림 애니메이션(1.2s) → 화이트아웃(0.5s) → 씬B 로드 |
| 예외 처리 | 로딩 3초 이상 지연 시 로딩 스피너 오버레이 표시 |

### 3-2. 씬B — 캐릭터 선택
| 기능 | 명세 |
|---|---|
| 캐릭터 배치 | 3체 캐릭터 1.5m 간격 배치, idle 루프 애니메이션(귀/꾬리) |
| 선택 판정 | 캐릭터별 하이라이트 링에 시선/터치 3초 유지 → 라디얼 프로그레스 0→100% → 완료 시 `selectCharacter(id)` 호출 |
| 중단 처리 | 3초 이내 시선 이탈 시 프로그레스 초기화(0%로 리셋, 감점 없음) |
| 선택 확정 후 처리 | 확대 줌인 애니메이션 → 화이트 플래시 → `characterId` 전역 상태 저장 → 씬C 진입 |

### 3-3. 씬C — 엄마 돼지와의 대화
| 기능 | 명세 |
|---|---|
| 대사 시퀀스 | `characterId`에 매핑된 대사 JSON을 순차 재생(엄마→주인공) |
| 좌우 둘러보기 반응 | 카메라 yaw ±30° 진입 시 형제 캐릭터의 idle-jump 애니메이션 트리거(단순 조건부 재생, 반복 가능) |
| 스킵 기능 | 우측 상단 스킵 버튼으로 전체 대사 생략 후 즉시 씬 종료 트리거 실행 가능 |
| 씬 종료 조건 | 마지막 대사 종료 → 문 열림 애니메이션 → 이동화살표 생성 |

### 3-4. 씬D — 갈림길에서 헤어짐
| 기능 | 명세 |
|---|---|
| 형제 퇴장 애니메이션 | 8초 walk-cycle 후 오브젝트 비활성화(destroy 또는 pooling) |
| 길 선택 로직 | `characterId`에 따라 활성화되는 길이 고정(첫째=좌, 둘째=중, 셋째=우 등 사전 정의) |
| 이동 트리거 | 화살표 탭 → 자동 보행 카메라(좌우 8° 흔들림) → 씬E 로드 |

### 3-5. 씬E — 재료 채집 & 건축 미니게임 (캐릭터별 분기)

#### (A) 첫째 — 짚집
| 단계 | 기능 |
|---|---|
| 오브젝트 | 짚단 12~15개 인스턴싱 배치, 그럽 시 스쿵쉬 애니메이션(0.9배) |
| 인터랙션 | 드래그하여 가이드 실루엣에 배치 → 스냅 판정(거리 임계값 내) → 정렬 + 반짝임 |
| 완료 조건 | 3단계(벽1층→벽2층→지붕) 스택 순차 완료 시 `buildComplete('straw')` 호출 |
| 완료 후 처리 | 완성 짚집 메쉬로 교체, 파티클 폭발, 씬F로 전환 |

#### (B) 둘째 — 나무집
| 단계 | 기능 |
|---|---|
| 오브젝트 | 나무판자 8~10개, 못 위치 마커(빨간 점) 표시 |
| 인터랙션 | 판자를 가이드 위치로 드래그 → 스냅 → 망치 아이콘 등장 → 3회 탭(또는 버튼 클릭)으로 못 박기 애니메이션 재생 |
| 카운트 로직 | 탭 카운트 3회 도달 시 해당 판자 고정 처리, 다음 판자 활성화 |
| 완료 조건 | 전체 판자(벽4면+지붕프레임) 완료 시 `buildComplete('wood')` 호출 |

#### (C) 셋째 — 벽돌집 (2단계)
| 단계 | 기능 |
|---|---|
| 1단계: 벽돌 제작 | ① 진흥 드래그→틀에 담기 ② 3회 탭으로 다지기 ③ 틀을 가마로 드래그→3초 로딩→벽돌 생성. 상단 카운터 UI(🧱 x/6)로 진행률 표시 |
| 2단계: 벽돌 쌓기 | 제작된 벽돌을 가이드 실루엣에 순차 배치, 배치마다 줄눈 이펙트 자동 생성 |
| 완료 조건 | 6개 벽돌 제작 + 전체 쌓기 완료 시 `buildComplete('brick')` 호출 → 씬H(형제 도착) 또는 씬F 분기 |
| 부가 연출 | 노을 라이팅 전환, 캐릭터 이마 땅방울 파티클 표시(연출용, 판정에는 영향 없음) |

### 3-6. 씬F — 늑대 습격 & 집 파괴
| 기능 | 명세 |
|---|---|
| 늑대 등장 트리거 | 집 완성 이벤트 후 일정 지연(예: 2초) 뒤 늑대 스폰 애니메이션 실행 |
| 대사 시퀀스 | 늑대→주인공→늑대(숨불기 예고) 순서로 자막 재생 |
| 숨불기 액션 | 볼 스케일 1.0→1.6배(0.8s) 후 원추형 바람 파티클 5m 확산 방출 + SFX |
| 파괴 물리 | 집 파츠를 개별 리지드바디로 전환, 파티클 충돌 시 랜덤 임펄스 적용(재료별 강도 상이: 짚>나무>벽돌(벽돌은 씬I에서 파괴 없음)) |
| 카메라 셰이크 | Perlin noise 기반, 강도는 재료별 사전 정의 값 사용 |
| 종료 조건 | 파괴 애니메이션 완료 후 자동으로 씬G(도망 미니게임) 진입 |

### 3-7. 씬G — 웹캠 모션인식 도망 미니게임
| 기능 | 명세 |
|---|---|
| 진입 전 처리 | 카메라 권한 요청 모달 표시 → 허용 시 `getUserMedia` 스트림 시작, 거부 시 즉시 폴백 모드로 전환 |
| 레이아웃 | 화면 좌 50%: 3D 캐릭터 달리기 컷씬(파랑랙 배경 스크롤) / 우 50%: 웹캠 미러 피드 + 스켈레톤 오버레이 |
| 관절 추적 | 어깨-팔꿈치-손목 좌표 프레임마다 추론(MoveNet Lightning) |
| 팔 들어올림 판정 | 손목 y좌표가 어깨 y좌표 대비 화면 높이 15% 이상 상승 시 해당 팔 `armUp = true` |
| 스텝 인정 로직 | 좌/우 어느 쪽이든 번갈아 들어올리는 패턴 감지 시 1스텝 인정(완화 로직, 만 4세 난이도 고려) |
| 게이지 UI | 10칸 세그먼트 바, 스텝 인정마다 1칸 채움 + 반짝임 파티클, 캐릭터 컬러로 채색 |
| 완료 처리 | 10칸 완료 시 무지개 반짝임 + 성공 SFX → 자동 페이드 전환하여 다음 씬 진입 |
| 폴백 로직(필수) | 30초간 게이지 미증가 시 "화면을 3번 터치해서 대신 도와줘!" 대체 버튼 노출, 3회 탭으로 동일하게 게이지 1칸씩 수동 증가 가능 |
| 인식 실패 피드백 | 관절 미검출 시 긍정적 톤의 안내 문구 표시("이 안에 팔이 보이게 움직여볼까?") |

### 3-8. 씬H — 다음 형제 집 도착 & 재회
| 기능 | 명세 |
|---|---|
| 트리거 | 씬G 완료 이벤트 수신 |
| 연출 | 문 두드리는 SFX → 문 열림 애니메이션 → 형제 캐릭터 진입 애니메이션 재생 |
| 상태 전이 | 합류한 형제를 동행 캐릭터 리스트에 추가(이후 씬 대사에 반영) |

### 3-9. 씬I — 벽돌집 최종 방어 + 해피엔딩
| 기능 | 명세 |
|---|---|
| 문 잠그기 인터랙션 | 자물쇠 오브젝트 1초 홀드 입력 → 다이얼 회전 애니메이션 + 잠금 SFX + 완료 이펙트 |
| 늑대 공격 판정 | 바람 파티클이 벽면 충돌 시 튀겨나가는 반사 이펙트만 발생, 리지드바디 임펄스 없음(카메라 셰이크 미적용) |
| 늑대 퇴장 | 2회 시도 실패 애니메이션(별 이펙트+주저앉기) 후 페이드아웃 퇴장 |
| 엔딩 시퀀스 | 형제 마무리 대사 → 콘페티 낙하(3초) → 캐릭터 댄스 루프 + BGM 전환 → 2초 후 도장 UI 호출(2-4 참고) |
| 종료 후 처리 | 씬A 복귀, "다른 돼지로 다시하기" 버튼으로 씬B 재진입 가능 |

## 4. 데이터 구조 (예시)

```json
{
  "gameState": {
    "characterId": "first | second | third",
    "currentScene": "E_build",
    "companions": ["first"],
    "gaugeProgress": 0,
    "checkpoints": {
      "lastSavedScene": "D_forest_split",
      "timestamp": "ISO8601"
    }
  }
}
```

| 필드 | 설명 |
|---|---|
| characterId | 최초 선택한 주인공 캐릭터 |
| currentScene | 현재 진행 중인 씬 ID |
| companions | 현재 동행 중인 형제 목록 |
| gaugeProgress | 미니게임 게이지 진행도(0~10) |
| checkpoints | 씬 전환 시 자동 저장되는 마지막 지점 |

## 5. 예외/에러 처리 공통 규칙

| 상황 | 처리 |
|---|---|
| 3D 에셋 로딩 실패 | 저해상도 placeholder 표시 + 백그라운드 재시도 |
| 오디오 재생 실패 | 자막 텍스트만으로 진행 가능하도록 설계(오디오 필수 의존 금지) |
| 웹캠 권한 거부/미지원 기기 | 즉시 대체 버튼(3회 탭) 미니게임으로 자동 전환, 카메라 관련 UI 전부 숨김 |
| 네트워크 끓김(온라인 요소가 있을 경우) | 로컬 캐시된 마지막 체크포인트로 복귀 |
