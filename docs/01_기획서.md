## 1. 프로젝트 개요

### 1-1. 한 줄 기획
"내가 직접 아기돼지 삼형제 중 한 마리가 되어, 1인칭 시점으로 숲속을 돌아다니며 집을 짓고 늑대를 피해 도망치는 3D 메타버스 동화."

### 1-2. 기획 배경
- 기존 동화 콘텐츠는 대부분 '읽어주는' 수동적 감상 형태에 그침.
- 만 4세 아동은 직접 캐릭터가 되어 행동할 때 몰입도와 이해도가 크게 상승.
- VR/3D 기술과 웹캠 모션인식을 결합해 "몸을 움직이며 이야기에 참여하는" 체험형 동화로 재구성.
- 수업 시연 목적상, 짧은 시간 안에 기승전결이 뚜렷하고 상호작용 포인트가 명확한 구조가 필요.

### 1-3. 교육적 목표
- 원작 동화의 교훈("성실함과 꾸준한 노력의 가치")을 체험을 통해 자연스럽게 전달
- 대근육 운동(팔 들어올리기)을 게임 미션과 연결하여 신체 활동 유도
- 유아 눈높이의 인과관계 학습: "튼튼하게 지으면 안전하다"는 결과를 직접 경험

### 1-4. 핵심 재미 요소 (Core Fun)
1. **캐릭터 이입** — 3마리 중 원하는 돼지를 선택해 관점이 다른 이야기를 체험
2. **손으로 짓는 집짓기** — 짚/나무/벽돌 각각 다른 조작감의 건축 미니게임
3. **몸으로 도망가기** — 웹캠으로 내 팔 동작이 그대로 게임 속 달리기로 연결되는 순간
4. **안전한 위기감** — 늑대는 무섭지 않고 코믹하게 표현, 실패해도 벌칙 없이 다음 형제 집으로 자연스럽게 연결
5. **협동과 재회** — 형제가 한 명씩 합류하며 마지막에 다 함께 승리하는 구조

## 2. 타겟 및 톤앤매너

| 항목 | 내용 |
|---|---|
| 연령 | 만 4세 (한글 미숙, 짧은 집중 시간 고려) |
| 대사 | 5~10단어 내외의 짧고 리드미컬한 문장, 의성어/의태어 적극 사용 (뚝딱뚝딱, 후우우, 철컥) |
| 비주얼 | 로우폴리 툰셰이딩, 파스텔톤, 둥근 실루엣 — 사실적 렌더링 지양 |
| 정서 | 항상 "괜찮아, 다시 하면 돼"의 긍정적 톤 유지. 공포보다는 유머 우선 |
| 실패 처리 | 실패라는 개념 자체를 최소화 — 늑대에게 집이 부서져도 다음 형제 집으로 자연스럽게 서사가 이어짐 |

## 3. 전체 게임 흐름 (플로우차트 개념도)

```
[씬A: 책표지] --들어가기--> [씬B: 캐릭터 선택(첫째/둘째/셋째)]
        │
        ▼ (선택한 돼지 기준으로 아래 공통 구조 반복/분기)
[씬C: 엄마와의 대화] → [씬D: 갈림길에서 헤어짐] → [씬E: 재료 채집·건축 미니게임]
        │
        ▼
[씬F: 늑대 습격 & 집 파괴] → [씬G: 웹캠 모션인식 도망 미니게임 (10칸 게이지)]
        │   (첫째, 둘째 루트에서만 발생 / 셋째는 최종 방어전으로 대체)
        ▼
[씬H: 다음 형제 집 도착 & 재회] → (다음 형제 루트 반복)
        │
        ▼
[씬I: 벽돌집 최종 방어(늑대 공격 실패)] → [엔딩: 축하 파티 + 도장 UI] → [씬A 복귀 / 다시하기]
```

### 3-1. 캐릭터별 진행 경로 요약
| 시작 캐릭터 | 진행 순서 |
|---|---|
| 첫째(짚) 선택 시 | 첫째 루트 → 도망 미니게임① → 둘째 집 → 도망 미니게임② → 셋째 집(최종방어) → 엔딩 |
| 둘째(나무) 선택 시 | 둘째 루트 단독 전개 → 첫째가 찾아옴 → 도망 미니게임 → 셋째 집(최종방어) → 엔딩 |
| 셋째(벽돌) 선택 시 | 셋째 루트(벽돌 제작 2단계) → 형들이 찾아옴 → 문 잠그기 → 최종방어 → 엔딩 |

> 어떤 돼지를 선택해도 최종적으로는 "셋째의 벽돌집에서 다 함께 안전해지는" 동일한 결말로 수렴하며, 각자의 시점에서 다른 대사·연출을 경험합니다.

## 5. 세계관 / 공간 구성

- **통나무집(엄마집)** → **숲속 갈림길** → **짚/나무/벽돌 재료 채집지** → **각 형제의 집** → **최종 벽돌집(해피엔딩 무대)**
- 시간 흐름: 맑은 정오(도입) → 각 집짓기 구간의 낮 → 벽돌 굽기 구간의 노을 → 엔딩의 따뜻한 실내 조명
- 공간은 모두 파스텔톤의 "동화책 일러스트가 3D로 살아난" 듯한 느낌으로 통일

---

## 6. 차별화 포인트 (수업 시연 어필 포인트)

1. 단순 시청형 동화가 아닌 **선택 → 행동 → 결과**의 3단 상호작용 구조
2. **웹캠 신체 인식**을 활용해 디지털 콘텐츠와 실제 신체 활동을 연결
3. 캐릭터 3인 중 무엇을 선택해도 서로 다른 대사/연출을 볼 수 있어 **재플레이 가치** 존재
4. 유아 정서 발달을 고려해 "실패해도 다음으로 자연스럽게 넘어가는" **무벌점 설계**

## 7. 개발 범위 (수업 시연 기준 MVP 제안)

| 우선순위 | 포함 범위 |
|---|---|
| 필수(Must) | 씬A(표지)~씬C(엄마 대화), 첫째 루트 전체(씬D~F, 짚집), 웹캠 도망 미니게임 1회, 씬I(엔딩) |
| 권장(Should) | 둘째 루트, 셋째 루트(벽돌 2단계 제작) 전체 구현 |
| 선택(Could) | 캐릭터 선택에 따른 대사 완전 분기, 재도전(다시하기) 후 다른 돼지 선택 시 이어보기 |
